# 한국어 숏폼 드라마 — Gemini Spark 스킬 (v3)

Google Flow로 **세로 9:16 한국어 숏폼 드라마**를 만드는 4단계 스킬입니다.
**스킬이 하는 일은 프롬프트를 내어주는 것입니다.** Flow 화면 조작은 사람이 직접 합니다.

| 단계 | 스킬 | AI와 함께 정하는 것 | 내어주는 프롬프트 | 비용 |
| --- | --- | --- | --- | --- |
| 1 | [drama-story](dist/drama-story.zip) | 주제·로그라인·인물 3명 | 기획 카드 + 외형 스케치 | `0` |
| 2 | [drama-world](dist/drama-world.zip) | 세계관·톤 + **캐릭터 4뷰 시트**·장소 시트 | 시트 프롬프트 · 성격 | `0` |
| 3 | [drama-shots](dist/drama-shots.zip) | **콘티 4패널 승인 → 키프레임 →** 10초 장면 | 콘티 · 키프레임 · 장면 | `0` → 영상 `7~15` |
| 4 | [drama-cut](dist/drama-cut.zip) | 진단 · 수정 · 보존 | 수정 프롬프트 | `7~15` |

각 스킬은 단독으로도 쓸 수 있고, 앞 단계의 결과 카드를 이어받아 쓸 수도 있습니다.

## v3에서 달라진 것

- **캐릭터를 "상반신 정면 1장"이 아니라 "4뷰 시트"로 만듭니다** (정면·3/4·측면·후면 전신 + 얼굴 클로즈업).
  상반신 1장에는 등·소매·신발 정보가 없어서 모델이 그 부분을 지어내고, 컷마다 옷이 달라집니다.
- **영상 만들기 전에 콘티 4패널로 승인받고, 그 패널을 키프레임 스틸로 뽑아 `프레임 → 시작`에 넣습니다.**
  문장만으로 지시하면 배경·행동·첫 구도가 매번 달라집니다.
- **이미지 단계는 전부 0 크레딧입니다** (Nano Banana 계열 3종 실측). 시트·장소 시트·콘티·키프레임은 몇 번을 다시 뽑아도 무료이고, 돈은 영상 `생성 시작`에서 처음 나갑니다.
- 옷이 두 벌이면 **새로 만들지 않고 편집으로 파생**합니다 — 새로 만들면 얼굴이 다른 사람이 됩니다.

## 설치 (Gemini Spark)

1. [Gemini Spark의 Skills 화면](https://support.google.com/gemini/answer/17094296?hl=ko)을 엽니다.
2. 위 표에서 스킬 이름을 눌러 ZIP을 받습니다. GitHub에서 **Download raw file**을 고릅니다.
   ZIP 최상위에 `SKILL.md`가 있고, `references/`에 규칙 문서와 그림이 함께 들어 있습니다.
3. Spark에서 **업로드**를 선택해 ZIP을 지정하고, 내용을 확인한 뒤 생성합니다. 네 개를 모두 쓰면 각각 업로드합니다.
4. 새 작업에서 `/`를 입력해 스킬을 고르거나, 관련 작업을 요청해 자동 적용합니다.
   첫 스킬에는 예를 들어 `2분짜리 가족 드라마를 기획하고 싶어. 9:16, 한국어 대사야.`라고 입력합니다.

Spark 스킬은 현재 만 18세 이상, 개인 Google 계정, 활동 기록 사용 설정이 필요합니다.
요금제 요건과 지원 지역은 [Google 공식 안내](https://support.google.com/gemini/answer/17094296?hl=ko)에서 확인하세요.

## 파일 구조

```
skills/
  drama-story/SKILL.md   + references/ (규칙 문서 4종 · 그림)
  drama-world/SKILL.md   + references/
  drama-shots/SKILL.md   + references/
  drama-cut/SKILL.md     + references/
dist/
  drama-story.zip  drama-world.zip  drama-shots.zip  drama-cut.zip   ← Spark 업로드용
```

`dist/*.zip`은 Spark에 바로 올리는 묶음입니다. `skills/` 아래 원본은 읽기·수정용입니다.

## 스킬이 하는 일 / 하지 않는 일

- **합니다**: 대화로 재료를 받아 **프롬프트 전문**을 만들어 줍니다. **붙일 위치**와 **판정 기준**을 함께 알려 줍니다.
- **하지 않습니다**: Flow 화면을 조작하지 않습니다. 클릭·입력·생성을 대신하지 않습니다.
  프롬프트를 복사해 붙이고, 설정을 고르고, `생성 시작`을 누르는 것은 사람입니다.

## 프롬프트 원칙 (요약)

- 지시문은 영어, **대사만 한국어**. 대사는 프롬프트 맨 앞에 한 문장만 넣습니다.
- **화면 속 한글은 후반 합성**입니다. 모델이 렌더링한 한글은 획이 무너집니다 → `No text overlay on screen.`
- 대사가 있는 샷은 **단일 샷으로 잠급니다** (`In a single unbroken scene, no scene cuts.`).
- 길이는 10초, 비율은 **9:16**을 명시합니다.
- 편집은 **4턴 안에** 끝냅니다. 더 필요하면 새로 만듭니다.
