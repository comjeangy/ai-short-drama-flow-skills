# 강의용 설치 · 진행 안내 (강사용)

## 1. 수강생에게 주는 것

- 저장소 주소: `https://github.com/comjeangy/ai-short-drama-flow-skills`
- 받을 것: `dist/drama-story.zip` · `drama-world.zip` · `drama-shots.zip` · `drama-cut.zip`

> GitHub에서 zip을 받을 때는 **Download raw file** 을 눌러야 한다(일반 다운로드는 HTML이 받힌다).

## 2. 수강생 계정 요건

| 항목 | 요건 |
|---|---|
| 연령 | 만 18세 이상 |
| 계정 | 개인 Google 계정 |
| 설정 | 활동 기록 사용 |
| 요금제 | Spark 스킬 요건은 [Google 공식 안내](https://support.google.com/gemini/answer/17094296?hl=ko) |

Flow 영상 생성에는 **크레딧**이 필요합니다. 이미지 단계(시트·콘티·키프레임)는 **0크레딧**이므로
수업 중에는 이미지 단계까지 전부 실습할 수 있습니다.

## 3. 수업 흐름 (4차시)

| 차시 | 스킬 | 하는 일 | 실습 산출물 | 크레딧 |
|---|---|---|---|---|
| 1 | drama-story | 주제·로그라인·인물 3명 | 기획 카드 | 0 |
| 2 | drama-world | 세계관 + 캐릭터 4뷰 시트·장소 시트 | 시트 프롬프트 | **0** |
| 3 | drama-shots | 콘티 승인 → 키프레임 → 10초 장면 | 콘티·키프레임·장면 | 0 → 영상 7~15 |
| 4 | drama-cut | 진단·수정·보존 | 수정 프롬프트 | 7~15 |

**3차시의 영상 생성은 수강생 각자 판단**입니다. 강사가 대신 `생성 시작` 을 누르지 않습니다.
`항상 승인` 은 절대 누르지 않게 미리 안내하세요 (이후 묻지 않고 자동 차감됩니다).

## 4. 수강생이 자주 막히는 곳

| 증상 | 안내 |
|---|---|
| zip을 올렸는데 스킬이 안 보인다 | Spark Skills 화면에 업로드했는지 · 활동 기록 설정 확인 |
| 옷이 자꾸 바뀐다 | 4뷰 시트를 만들었는지 · 2벌은 **편집 파생**인지 |
| 화면 글자가 깨진다 | 화면 글자는 **후반 합성**입니다. 프롬프트에 금지 문구가 있는지 |
| 첫 컷이 매번 다르다 | 키프레임을 `프레임 → 시작` 에 넣었는지 |
| 크레딧이 두 번 나갔다 | 생성 버튼을 두 번 눌렀는지 (진행 표시 확인) |

## 5. 강사용 점검 도구

```bash
python3 scripts/check_prompt.py <수강생 프롬프트 파일>   # 규칙 준수 검사
python3 scripts/selftest.py .                          # 저장소 구조 점검
```

수강생 프롬프트를 검수기에 돌리면 **어느 규칙이 빠졌는지** 바로 나옵니다(9:16 · 글자 금지 · 대사 언어 · 단일 샷 잠금 등).
