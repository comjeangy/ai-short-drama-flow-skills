# 예제 — 실제로 만든 것

> 말로 설명한 게 아니라 **실제로 만들어서 승인받은 기록**이다.
> 크레딧·판정·실패를 그대로 남겼다. 그대로 따라 하면 같은 순서로 만들 수 있다.

| 예제 | 내용 | 상태 |
|---|---|---|
| **`ep01/`** | 「셔터」 EP001 — 기획 → 캐릭터 시트 3명 → 장소 시트 → 콘티 4패널 → 키프레임 → 10초 장면 | 이미지 전 단계 승인(0크레딧) · 영상 대기 |

## 읽는 순서

`00-project-card.json` → `01-기획.md` → `02-캐릭터-시트.md` → `03-장소-시트.md` → `04-콘티.md` → `05-키프레임.md` → `06-장면.md`

각 문서 끝에 **판정**이 있다. `render-log.csv`(생성 로그) · `judgement.jsonl`(판정 기록)도 같이 본다.

## 이 예제가 보여주는 것

- **이미지 단계는 전부 0크레딧** — 시트·장소·콘티·키프레임을 다 만들어도 0
- **영상만 유료** — 360p 10초 = 7크레딧 (720p = 15)
- **콘티로 먼저 승인받는다** — 영상 크레딧을 버리지 않는다
- **2벌 캐릭터는 편집 파생** — 새로 만들면 얼굴이 바뀐다
- **콘택트시트는 영상 입력 불가** — 키프레임 스틸을 따로 만든다
