# 기획 카드 — 1차시 산출물 (2026-09-29 · **v3 확정**)

> 이 카드는 **Flow에 넣지 않는다.** 종이(또는 이 파일)에 둔다.
> 세계관·클립 구조·캐릭터 확정본은 `world_style.md`, 캐릭터별 상세는 `../characters/`.

```
────────────────────────────────────────────────
제목(가제): 셔터
주제      : 40년 웃기만 하던 국숫집 노인이, 갑질 손님에게 처음으로 문을 닫고 컨버터블을 타고 떠난다
감정      : 속이 시원함 (사이다)
장르 톤   : 사실적인 한국 드라마 톤 + 숨은 재력가 반전
배경/시간 : 정오 · 재래시장 한가운데 국숫집 + 시장 앞 도로 (하얀 직사광, 시장 소음)
톤        : 차갑게 — 강한 콘트라스트, 회색 콘크리트, 빨간 차체 한 점만 채도
구조      : 2클립 (A 10초 대사 샷 + B 10초 와이드) → 편집 후 약 20초
────────────────────────────────────────────────
```

## 3비트 — 클립별

### 클립 A · 국숫집 앞 (미디엄 · 단일 잠금 · 대사 있음)
```
[0-3초]  훅    — 미영이 다 먹은 빈 그릇을 카운터에 쿵 밀어놓으며 비웃듯 말한다.
                  만복의 웃음이 멈춘다.
                  ★ 뒤편 흐릿하게 빨간 컨버터블이 세워져 있다 (1차 단서)
[3-6초]  반전  — 만복이 아무 말 없이 앞치마 끈을 풀어 카운터에 내려놓는다.
                  왼손목의 낡은 가죽줄 금속 시계가 드러난다 (2차 단서)
[6-10초] 여운  — 만복이 셔터 줄을 당긴다. 영업 중인 셔터가 내려온다.
                  옆 가게 순자가 잡음에 놀라 고개를 든다
```

### 클립 B · 셔터 앞 · 시장 앞 도로 (와이드 · 무대사)
```
[0-4초]  셔터가 닫힌 채. 미영이 셔터 앞에 서 있다. 순자가 자기 가게 문에서 지켜본다
[4-10초] 정장 차림으로 머리를 정돈한 만복이 걸어 나와 빨간 컨버터블 문을 열고 앉는다.
         시동음. 미영은 비참하게 바라본다. 순자가 미영을 한 번 보고 입을 다문다
         (두 여자는 정지, 움직이는 건 만복 한 명뿐)
```

🔑 **환복은 클립 경계에서 일어난다.** 셔터가 닫히면 관객은 안을 못 보고, 다시 열리면 다른 사람이 되어 있다. **설명이 필요 없다.**

## 대사 (한 문장만)

```
미영이 비웃으며 말한다: "다 먹었는데 맛이 없네요, 이 나이 먹고 장사 그렇게 하세요?"
in Korean, sneering and sharp tone, fast delivery
```

→ 만복은 **대사가 없다.** 반박 대신 **차를 타고 떠난다.** 이게 이 편의 사이다다.

## 진단 기록 (왜 이렇게 됐나)

| 버전 | 문제 |
|---|---|
| v1 (셔터만 내림) | 셔터를 내리는 건 **만복이 장사를 접는 것**. 손해는 만복이 보고 **미영은 아무것도 잃지 않는다** → 응징이 아니라 체념 |
| v2 (컨버터블 추가) | 만복이 이긴다 ✓ / 그러나 **환복을 10초 한 클립에 넣으면 6동작** → 실패 |
| **v3 (2클립 분할)** | 환복을 **셔터 뒤로 숨긴다.** 클립당 동작 3개 이하 유지 ✓ |

## 🔑 반전을 읽히게 하는 단서 3개

| # | 단서 | 언제 | 왜 |
|---|---|---|---|
| 1 | 뒤편 도로의 **빨간 컨버터블**(흐릿하게) | 클립 A · 0초부터 | 마지막 동선이 예고되지 않으면 **우연으로 보인다** |
| 2 | 앞치마를 벗을 때 **손목의 낡은 시계** | 클립 A · 3-6초 | "이 노인은 원래 이런 사람이 아니다"를 한 프레임으로 |
| 3 | **정장 차림** | 클립 B 전부 | 환복 자체가 반전 |

단서는 **대사로 설명하지 않는다.** 소품만으로 처리한다.

## 차량 소품 — 실무 주의

- 🔴 **프롬프트에 "Porsche", "911" 브랜드명을 쓰지 않는다.**
  → 엠블럼·번호판에 글자가 생기고, **글자는 붕괴한다**(CJK·라틴 모두).
  → 차체 형태로 읽히게 쓴다: `a bright red low-slung classic convertible sports car, round headlights, no badges, no license plate`
- **타기 + 출발**을 한 비트에 넣지 않는다 → 클립 B는 **문을 열고 앉는 순간까지**. 출발은 **시동음**으로만

## 금지 세트 (꼬리말 — 매 프롬프트에 자동 첨부)

```
No text overlay on screen. No Korean text, no signboards with letters, no captions, no watermark.

```

🔴 **정오 시장 배경 주의**: 시장엔 간판·현수막·가격표가 많다.

상점 간판이 프레임에 들어오는 앵글은 피하고, 필요하면 후반 합성한다.
