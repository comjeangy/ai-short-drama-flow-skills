# EP001 · 2차시 산출물 — 장소 시트 ([L1] · [L2])

> 장소는 **한 번 만들어 모든 샷에 붙인다.** 문장으로 매번 설명하면 배경이 매번 달라진다.
> 이 파일은 `world_style.md`·`location_sheet.md` 를 이 예제로 옮긴 것이다.

# 로케이션 시트 — 「셔터」 (3차시 보강 · 2026-09-29)

> **사용자 교정에서 나온 자산**: *"캐릭터뿐만 아니라 배경 이미지도 만들어 놔야 잘 유지가 되는 거 같아."*
>
> 캐릭터는 `@` 참조 자산이 있어서 얼굴이 유지된다.
> **배경은 참조 자산이 없으면 매 생성마다 새로 발명된다** → 컷마다 다른 시장이 나온다.
> → 캐릭터와 **똑같은 구조**로 배경도 고정한다.

## 장소 접미어 — 모든 장면 프롬프트에 붙인다

스타일 전역이 **톤**을 고정한다면, 장소 접미어는 **공간**을 고정한다. 둘 다 필요하다.

```
[L1] 재래시장 한가운데 국숫집 앞. 낡은 철제 셔터, 긁힌 스테인리스 카운터,
     낮은 의자, 채도 낮은 회색빛 황토 어닝. 뒤편 도로에 빨간 컨버터블이 흐릿하게.

[L2] 같은 국숫집의 바깥 도로 쪽. 닫힌 낡은 철제 셔터, 회색 아스팔트,
     왼쪽에 옆 가게 입구, 중간 거리에 빨간 컨버터블.
```

영어판:
```
[L1] The counter side of a small noodle shop in a traditional Korean market at noon:
     a worn corrugated steel roller shutter, a scratched stainless counter, low stools,
     a faded grey-beige awning. Far behind, a red convertible out of focus.

[L2] The street side of the same noodle shop: a closed worn steel shutter, grey asphalt,
     a neighbouring stall entrance on the left, a red convertible parked in the middle distance.
```

## 붙이는 순서 (Flow)

```
1. 프로젝트에서 배경 이미지 L1 · L2 생성         ← 비용 확인 필요 (아래)
2. 그 이미지를 애셋으로 업로드
3. 프롬프트 상자에서 @ → 애셋 피커 → 이미지 → L1 선택 → `프롬프트에 추가`
4. 캐릭터 3명도 같은 방식으로 @ 붙이기 (한 명씩)
5. P5 프롬프트 붙여넣기 → ⚙ 설정 9:16 → 생성 시작
```

> 애셋 피커에 **`이미지`** 와 **`업로드`** 항목이 실물로 확인돼 있다(2026-09-29).
> 문자로 장소를 설명하는 것보다 **이미지를 참조시키는 쪽이 훨씬 강하다.**

## ✅ 실측으로 확정된 것 (2026-09-29 라이브 DOM 스냅샷 · `research/live/`)

| # | 질문 | 결과 |
|---|---|---|
| 1 | 애셋 피커에 이미지/업로드가 있나 | ✅ **있다.** 탭 = `전체 / 이미지 / 동영상 / 음성 / 캐릭터 / 아바타 / 업로드` + `미디어 업로드` + `애셋 검색` |
| 2 | 시작 프레임(키프레임) 고정 UI가 있나 | 🔴 **없다.** `⚙ 설정`에는 **비율·개수·모델**만 있고 **프레임·소재·길이 항목이 없다.** 동영상 모델 메뉴도 모델 4종 선택뿐 |
| 3 | 이미지 생성 모델은 | ✅ `🍌 **Nano Banana 2 Lite**` — **캐릭터 만들기와 같은 모델(실측 0크레딧)** |
| 4 | 이미지 비율에 9:16이 있나 | ✅ 있다. 이미지 = `16:9 / 4:3 / 1:1 / 3:4 / 9:16` · 동영상 = `16:9 / 9:16` |

**→ 따라서 배경 고정 경로는 하나뿐이다: 이미지 자산을 만들어 업로드 → `@` 로 참조.**
프레임 고정은 기대하지 말 것. 매뉴얼의 "동영상 프레임" 설명은 **실물 화면과 다르다.**

| # | 남은 미확인 | 확인 방법 |
|---|---|---|
| 1 | 프로젝트 **이미지 생성이 크레딧을 쓰는가** | 이미지는 Nano Banana 2 Lite = 캐릭터와 같은 모델이므로 **무료일 가능성이 높다.** 생성 전후 계정 패널 크레딧 숫자 비교 (0원) |
| 2 | `@`로 배경을 참조하면 **실제로 배경이 고정되는가** | 클립 A를 L1 붙여 생성 → 컷 간 배경 동일성 눈으로 비교 (15크레딧) |
