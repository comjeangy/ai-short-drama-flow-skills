## 조작 메모 (다음에 그대로 쓸 것)

1. **소재 붙이는 경로 (실측)**: 프롬프트 상자에서 **`@` 입력** → 피커 열림 → 목록 항목 클릭 → **`프롬프트에 추가`** → 상자에 `<span class="mention-chip" data-mention-id="…">` 로 삽입됨.
   - `@` 도 **execCommand 로 넣어야** 피커가 열린다. 피커를 여는 별도 버튼(aria-label `프롬프트 상자에 소재 추가`)은 클릭만으로는 안 열렸다.
   - 피커 왼쪽 분류: 전체 / 이미지 / 동영상 / 음성 / 캐릭터 / 아바타 / 업로드.
2. **좌표 변환 주의**: 화면 캡처는 물리 픽셀(1368×737), 클릭 좌표는 CSS 픽셀(1710×921) — **물리 ÷ 0.8 = CSS**. 이걸 착각해 처음에 빈 곳을 클릭했다.
3. **생성 후 페이지가 갱신되어 CDP 세션이 끊긴다** → `fc.py '{"op":"attach"}'` 로 재접속해야 스크린샷이 된다.
4. **비율 클릭(16:9)이 반영되지 않는다.** 2x2 콘티는 가로가 유리하니 다음엔 비율 선택 경로를 다시 확인할 것.
