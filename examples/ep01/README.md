## 실측에서 배운 것

1. **이미지 단계에는 승인 창이 없다.** 시트·콘티·키프레임을 아무리 만들어도 잔액이 줄지 않는다(869→869).
2. **비율 선택이 안 먹는다.** 16:9를 눌러도 9:16으로 나온다 → 프롬프트에 `9:16` 을 직접 쓴다.
3. **시트 제목이 그리드에서 잘린다** → 캐릭터 이름을 제목에 붙인다(`미영 시트`).
4. **정장 만복은 편집 파생**으로 만들었다. 새로 생성하면 얼굴이 바뀐다.
5. **콘티(콘택트시트)는 영상 입력으로 못 쓴다** → 키프레임을 따로 만들어 `프레임 → 시작` 에 넣는다.
