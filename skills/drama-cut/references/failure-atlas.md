# 실패 사전 — 증상 → 원인 → 처방

> AI가 진단할 때 쓰는 표. **증상은 관찰, 원인은 추정, 처방은 프롬프트 변경**이다.
> 실패한 프롬프트도 지우지 않는다 — 실패 유형 자체가 자산이다.

---

## 1. 이미지 단계 (시트·장소·콘티·키프레임 · 0크레딧)

| 증상 | 진짜 원인 | 처방 |
|---|---|---|
| 옷 디테일이 컷마다 다르다 | 시트에 뒷면 정보 없음 | **4뷰 시트로 다시** (`character-consistency.md`) |
| 옷 무늬가 흔들린다 | 무늬를 글로만 씀 | 무늬 명시 + 금지변화 등록 |
| 2벌인데 얼굴이 바뀐다 | 새로 생성했다 | **편집 파생** |
| 시트에 글자·라벨이 들어간다 | 글자 금지 누락 | `No text, no letters, no numbers, no panel labels` |
| 콘티가 3패널·5패널로 나온다 | 패널 수 미명시 | `exactly 4 panels in one 2x2 … Do not create additional panels` |
| 콘티에서 같은 동작이 반복된다 | 패널별 행동 미지정 | `PANEL 1: …` 로 행동 하나씩 |
| 배경이 패널마다 다르다 | 장소 접미어 누락 | `LOCATION: {장소 접미어}` 를 넣는다 |
| 콘티가 설명문을 써 버린다 | 첫 줄 지시 누락 | 맨 앞에 `GENERATE THE STORYBOARD IMAGE NOW.` |
| 인물이 시트와 다르다 | 참조를 안 붙였다 | `@` 로 시트 붙이기 + `Use the attached character sheet as the authoritative reference` |

## 2. 영상 단계 (유료 · 크레딧 확인)

| 증상 | 진짜 원인 | 처방 |
|---|---|---|
| 장면이 3번 바뀐다 | 단일 샷 잠금 누락 | `In a single unbroken scene, no scene cuts.` |
| 화면에 글자가 깨진다 | 배제 문구 누락 | `No text overlay on screen.` (한글은 후반 합성) |
| 첫 컷 구도가 매번 다르다 | 시작 프레임 없음 | 키프레임 스틸을 `프레임 → 시작` 에 |
| 배경·행동이 상상과 다르다 | 문장만으로 지시 | **콘티를 먼저** (0크레딧) |
| 10초가 늘어진다 | 비트 2개 이하 | 3비트 타임코드로 다시 |
| 10초에 아무것도 안 남는다 | 비트 4개 이상 | 하나를 빼고 그 하나를 길게 |
| 대사가 안 들린다 | 대사가 여러 개 / 로마자 / 와이드 샷 | 한 문장·한국어 그대로·미디엄으로 |
| 소리가 없다 | (실측상 정상) 270p GIF 로 받았다 | **720p 원본**으로 다시 받는다 |
| 움직임이 뭉개진다 | 무빙 2개 이상 / 편집 4턴 초과 | 무빙 하나만 · 새로 생성 |
| 인물이 갑자기 커진다·작아진다 | `zoom` + `push in` 충돌 | 무빙 하나만 남긴다 |
| 같은 장면을 두 번 만들었다 | 생성 버튼을 두 번 눌렀다 | 승인 창·진행 표시를 끝까지 본다 (크레딧 2배) |

## 3. 편집 단계

| 증상 | 진짜 원인 | 처방 |
|---|---|---|
| 고쳐도 계속 이상하다 | 4턴 초과 | **새로 생성**한다 (크레딧을 두 번 쓰지 않는다) |
| 바꾼 것 말고도 바뀐다 | `나머지는 그대로` 누락 | 그 문장을 반드시 붙인다 |
| 편집 지시가 무시된다 | 설명이 너무 길다 | 바꿀 것 하나만 한 문장으로 |
| 편집 결과가 흐려진다 | 턴 누적 | 이미지 단계로 돌아간다 |

## 4. 이야기 단계 (프롬프트로 안 고쳐진다)

| 증상 | 원인 | 처방 |
|---|---|---|
| 갈등이 안 보인다 | 일상으로 시작 | 개막 공식(극단 상황 + 반상식) |
| 감정이 안 전달된다 | 형용사로 씀 | 몸의 움직임으로 (`shot-grammar.md` §5) |
| 장면이 산만하다 | 10초에 사건이 여러 개 | 3비트로 압축 |
| **3회 연속 방향이 틀렸다** | **프롬프트 문제가 아니다** | **1~2차시로 돌아간다** (이야기·콘티를 고친다) |

---

## 5. 진단 순서 (AI가 따르는 순서)

```
1. 증상이 어느 단계인가?  (이미지 / 영상 / 편집 / 이야기)
2. 참조 자산이 붙어 있었나?  (시트·장소·키프레임)
3. 필수 문구가 빠졌나?  (단일 샷 잠금 · 글자 금지 · 9:16)
4. 구조가 깨졌나?  (5부 순서 · 대사 위치 · 비트 수)
5. 그래도 안 되면 → 프롬프트 문제가 아니다. 이전 단계로 돌아간다
```

**한 번에 하나만 바꾼다.** 두 개를 바꾸면 무엇이 효과였는지 알 수 없다.
