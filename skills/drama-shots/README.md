# drama-shots (3차시)

**Use when you are about to make the video: storyboard sign-off → keyframe → 10-second shot.**

영상을 만들기 **전에** 콘티로 승인받고, 첫 컷을 키프레임 스틸로 뽑아 `프레임 → 시작` 에 넣는다.

| | |
|---|---|
| 입력 | 2차시 시트 + 장소 시트 |
| 나오는 것 | ① 콘티 4패널 프롬프트 ② 키프레임 스틸 프롬프트 ③ 10초 장면 프롬프트(5부 구조) |
| 비용 | 이미지 `0` → 영상 **360p 7 / 720p 15** (10초) |
| 다음 | [drama-cut](../drama-cut) — 진단·수정 |

## 순서 (건너뛰지 않는다)

```
① 4패널 콘티 (0크레딧) → ② 승인 → ③ 키프레임 스틸 (0크레딧)
→ ④ 프레임 → 시작 → ⑤ 장면 프롬프트 → ⑥ 생성 (7~15크레딧) → ⑦ 판정
```

- 콘택트시트(4패널)는 **영상 입력으로 못 쓴다** → 키프레임을 따로 만든다.
- 대사 샷은 **단일 샷으로 잠근다** (`no scene cuts`).
- 10초는 **3비트** 타임코드로 쪼갠다.
