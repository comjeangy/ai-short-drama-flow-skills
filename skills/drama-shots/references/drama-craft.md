# 드라마 설계 — AI와 함께 정하는 순서

> **이 스킬의 일은 Flow 설명이 아니다.**
> 드라마의 주제를 AI와 소통하며 정하고 디테일화하고, **그 결과를 프롬프트로 써 주는 것**이다.
> Flow 조작은 사람이 알아서 한다. 그래서 붙여넣기 안내는 `flow-paste.md` 한 장으로 끝낸다.
>
> 이 문서는 **AI가 무엇을 물어보고 무엇을 판단할지**의 근거다.
> 출처: 중국 숏드라마 실무 자료 + Google 공식 프롬프트 가이드 (2026-09 조사)

---

## 1. 10초 드라마의 뼈대 — **3비트**

중국 실무의 "타임스탬프로 쪼개기"를 10초에 맞춘 것이 구글 Omni의 **브래킷 타임코드**다.

```
[0-3초]   훅      — 시선을 붙잡는 한 장면
[3-6초]   반전    — 관계나 상황이 뒤집힌다
[6-10초]  여운    — 표정·시선·정지로 끝낸다
```

**10초에 3비트.** 이게 안 들어가면 10초가 늘어진다.
반대로 4비트 이상 넣으면 아무것도 안 남는다.

**AI가 물어볼 것**: "이 장면에서 **가장 중요한 한 순간**이 언제인가요?"
→ 답이 나오면 그 순간을 **3-6초(반전)** 칸에 놓고 나머지를 앞뒤로 채운다.

---

## 2. 개막 공식 — **일상으로 시작하지 않는다**

> 중국 현장 원칙: *"개막은 절대 일상에서 시작하지 않는다. 기상·걷기·잡담으로 시작하지 말 것."*

```
누구 + 어떤 극단 상황 + 반상식적 행동/발언
```

| ❌ 일상 시작 | ✅ 극단 상황 + 반상식 |
|---|---|
| "한 남자가 편의점에 들어온다" | "젖은 남자가 우산을 접지도 않고 문을 밀어 연다" |
| "두 사람이 이야기한다" | "여자가 남자에게 '여기서 뭐 하는 거예요?'라고 묻고, 남자는 대답 대신 고개를 돌린다" |

**2초 안에 이탈을 막아야 한다.** 10초짜리는 **첫 프레임이 곧 사건**이다.

**AI가 물어볼 것**: "이 인물이 **평소라면 하지 않을 행동**이 무엇인가요?"

## 3. 5막 구조를 10초로 압축

중국의 단편 5막(충돌 오프닝 → 정보 보완 → 갈등 심화 → 감정 전환 → 서스펜스)을
10초에 맞추면 **3막**이 된다.

| 10초 | 5막 대응 | 넣을 것 |
|---|---|---|
| 0-3초 | 제1막 충돌 오프닝 | 사건 발생. 배경 설명 금지 |
| 3-6초 | 제3막 갈등 심화 | 감정이 **한 단계만** 올라간다 (2~3단계는 10초에 안 들어간다) |
| 6-10초 | 제4막 감정 전환 | **사이다(爽) 또는 눈물(虐) 중 하나.** 둘 다는 안 된다 |

**"3+3+3 법칙"의 10초판**: 훅 1개, 기복 1번, 갈등 1개.
30초짜리에서 3개씩 쓰는 것을 10초는 **1/3로 줄인다.**

**AI가 물어볼 것**: "마지막에 관객이 **속이 시원해야** 하나요, **마음이 아파야** 하나요?"
→ 이 한 질문이 6-10초 칸의 연출을 결정한다.

## 4. 인물 자산 — **고정항목 + 금지변화**

중국 실무의 캐릭터 카드에서 **정말 중요한 두 줄은 이것뿐**이다.

| 줄 | 하는 일 |
|---|---|
| **고정항목** | 영상마다 반드시 같아야 하는 것 (머리·옷·얼굴 특징) |
| **금지변화** | AI가 **멋대로 발명하면 안 되는 것** |

```
고정항목: 어깨까지 오는 검은 단발, 붉은 트렌치코트, 서늘한 눈매
금지변화: 긴 머리 금지, 교복 금지, 밝은 미소 금지, 안경 추가 금지
```

**"금지변화"가 없으면 2편째부터 다른 사람이 된다.** 외형 프롬프트에 이 줄을 꼭 붙인다.

**AI가 물어볼 것**: "이 인물의 **얼굴에서 절대 바뀌면 안 되는 한 가지**는 무엇인가요?"

## 5. 세계관 — **스타일 전역 1개**

중국 실무는 스타일을 **전역(global) 하나**로 고정하고 모든 장면에 같은 접미어를 붙인다.
10초 짧은 영상에서는 이게 **시리즈를 이어 붙이는 유일한 방법**이다.

정할 것 4개:

| # | 항목 | 예 |
|---|---|---|
| 1 | **장르 톤** | `사실적인 한국 드라마 톤` |
| 2 | **빛** | `차가운 형광등, 젖은 아스팔트 반사광` |
| 3 | **색** | `탁한 청록 + 형광등의 흰색` |
| 4 | **시점/거리** | `얕은 심도, 인물 중심 미디엄 샷` |

**AI가 물어볼 것**: "이 이야기를 **낮에** 보여줄까요, **밤에** 보여줄까요?"
→ 밤/낮이 색과 조명을 한 번에 정해 준다.

### 한국 정서 미장센 (조사 자산)

한국 드라마로 보이게 하는 소품·공간. **배경을 정할 때 AI가 후보로 제안한다.**

| 축 | 자산 |
|---|---|
| 공간 | 편의점, 골목, 옥탑방, 지하철 계단, 국숫집, 노래방, 병원 복도, 아파트 놀이터 |
| 사물 | 형광등, 자판기, 컵라면, 비닐우산, 어묵 국물, 라이터, 삐삐 같은 낡은 휴대폰 |
| 날씨 | 비, 눈, 여름밤 습기, 겨울 입김 |
| 빛 | 형광등(편의점), 가로등(골목), 네온(노래방) |

> **주의**: 화면에 한국어 글자가 들어갈 자리는 만들지 않는다.
> 간판·서류·휴대폰 화면의 한글은 **깨진다**(실측 + 독립 검증). 필요하면 후반 합성이다.

### ★ 배경도 자산이다 — **로케이션 시트**

**스타일 전역이 톤을 고정해도, 배경은 고정되지 않는다.**
캐릭터는 참조 자산(`@`)이 있어 얼굴이 유지되지만, **배경에는 참조 자산이 없다.**
→ 그래서 컷마다 다른 시장·다른 골목이 나오고, 구도와 의상까지 같이 흔들린다.

**장소도 캐릭터와 같은 방식으로 자산화한다.**

```
로케이션 시트 (사람 없는 빈 배경 이미지) 1장 + 고정항목/금지변화 + 장소 접미어 1줄
```

| 규칙 | 이유 |
|---|---|
| **사람 없는 빈 배경**으로 만든다 | 인물을 바꿔 끼울 수 있어야 한다 |
| **앵글마다 한 장** | 같은 장소라도 카운터 방향/도로 방향은 다른 시트다 |
| 배경 시트에 **글자 금지**를 넣는다 | 간판·현수막·가격표 글자는 깨진다 |
| 장소 접미어를 **모든 장면 프롬프트에** 붙인다 | 스타일 전역은 톤만 잠근다. 공간은 따로 잠가야 한다 |

영상 프롬프트에서는 **업로드한 배경 이미지를 `@`로 참조**시킨다. 문자 설명보다 훨씬 강하다.

**실물 화면 기준(2026-09-29)** — 배경 고정에 쓸 수 있는 것은 이것뿐이다.

| | |
|---|---|
| ✅ 있는 것 | 애셋 피커 탭 `전체 / 이미지 / 동영상 / 음성 / 캐릭터 / 아바타 / 업로드` + `미디어 업로드` |
| ✅ 있는 것(정정) | **동영상 모드의 `프레임`** → `시작` / `종료` 슬롯이 있다 (2026-09-30 실측). 이미지 모드 패널에는 없다 |
| 배경 시트 만드는 법 | `⚙ 설정 → 이미지 → 🍌 Nano Banana 2 Lite → 9:16` (캐릭터와 같은 모델) |

## 6. 검수 4라운드 → **10초 실전 2라운드**

중국 실무는 검수에 4라운드를 쓴다(진단 → 작업서 → 시청각 대본 → 제작 가능성 심사).
10초 한 편에는 **2라운드면 충분**하다.

| 라운드 | AI가 하는 일 | 물어볼 것 |
|---|---|---|
| **1. 진단** | 만든 영상의 문제를 **원인별로** 분류 | "무엇이 마음에 안 드나요? (얼굴 / 장소 / 동작 / 소리 / 길이)" |
| **2. 잠금** | 못 고치는 것은 **후반 작업으로 넘긴다** | "이건 모델이 못 합니다. 편집에서 처리하시겠어요?" |

### "고난도 표기" — 모델에게 시도하지 말아야 할 것

중국 실무에서 가장 실전적인 항목. **AI가 먼저 "이건 안 된다"고 말해 줘야 한다.**

| 안 되는 것 | 대신 |
|---|---|
| 화면 안의 정확한 한글 | 후반 합성 |
| 복잡한 다인 동작 (3명이 동시에 다른 동작) | **한 명씩 순서대로** 움직이게 하고 컷으로 잇기 |
| 빠른 카메라 회전 + 고정 카메라 동시 지시 | 하나만 |
| 그림자 분리, 연속 동작 | 여러 샷으로 나눠 편집으로 속도감 |

> **3회 연속 방향이 틀렸으면 프롬프트가 아니라 이야기·콘티가 틀린 것이다.**
> 이때는 1~2차시로 돌아간다. 프롬프트를 더 만지지 않는다. (중국 실무 원칙)

## 7. AI가 지킬 대화 규칙

| 규칙 | 이유 |
|---|---|
| **한 번에 하나만 묻는다** | 초보자는 질문 3개를 받으면 멈춘다 |
| **선택지를 주고 고르게 한다** | "어떻게 할까요?"는 답이 안 나온다 → "① 비 오는 밤 ② 눈 오는 밤 중 어느 쪽?" |
| **정해지면 되읽어 준다** | "지금까지 이렇게 정리했습니다: … 맞나요?" |
| **결정한 것은 다시 묻지 않는다** | 같은 걸 세 번 물으면 신뢰가 깨진다 |
| **모르면 후보를 제안하고 고르게 한다** | 대신 정해 주지 않는다 (사용자가 고른다) |
| **막히면 축소한다** | "그럼 이번 편은 인물 2명으로 줄여 볼까요?" |
| **결과물은 항상 복사 가능한 블록으로 준다** | 사용자가 Flow에 붙여넣어야 한다 |
