# drama-story (1차시)

**Use when you need a concept, logline and three characters for a vertical Korean short drama.**

AI와 대화하며 **주제 · 로그라인 · 인물 3명 · 3비트 뼈대**를 정한다.
Flow에 넣을 프롬프트가 아니라 **종이에 두는 기획 카드**를 만든다.

| | |
|---|---|
| 입력 | 만들고 싶은 느낌 한 문장 (예: `사이다 나는 이야기`) |
| 나오는 것 | 기획 카드 (`assets/project-card.json` 양식) · 인물 외형 스케치 |
| 비용 | `0` |
| 다음 | [drama-world](../drama-world) — 세계관·캐릭터 시트 |

## 참조 문서

`references/prompt-recipes.md`(색인) · `prompt-anatomy.md` · `drama-craft.md` · `character-consistency.md` ·
`cost-and-safety.md` · `failure-atlas.md` · `flow-paste.md`

## 예

```
사이다 나는 2분짜리 가족 드라마를 만들고 싶어. 9:16 한국어 대사야.
```

AI가 되물어 주제·감정·인물을 좁히고, **3비트(훅·반전·여운)** 까지 채운 카드를 내어준다.
