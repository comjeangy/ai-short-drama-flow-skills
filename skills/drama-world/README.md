# drama-world (2차시)

**Use when you need consistent characters and locations: 4-view sheets, not one front-facing photo.**

세계관·톤을 정하고 **캐릭터 4뷰 시트**(정면·3/4·측면·후면 전신 + 얼굴 클로즈업)와 **장소 시트**를 만든다.
이 단계가 **컷마다 옷이 바뀌는 문제**를 막는다.

| | |
|---|---|
| 입력 | 1차시 기획 카드 |
| 나오는 것 | 시트 프롬프트(영어 전문) · 장소 접미어 `[L1]` · 성격 |
| 비용 | **`0`** — 이미지 모드는 승인 창이 없다(실측) |
| 다음 | [drama-shots](../drama-shots) — 콘티·키프레임·장면 |

## 핵심 규칙

- **상반신 정면 1장 금지** — 등·소매·신발 정보가 없으면 모델이 지어낸다.
- **2벌 의상은 편집 파생** — `Change only the clothing: …` (새로 만들면 얼굴이 바뀐다)
- 시트 제목에 **캐릭터 이름**을 붙인다(Flow 그리드에서 잘려 보인다).
- 장소는 **한 번 만들고 접미어로 모든 샷에 붙인다.**
